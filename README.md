# 中国国家发展模拟器

一款从 1949 年开始、以月为最小推进单位的国家经营模拟游戏。项目优先建设完全独立于界面的确定性模拟核心，再通过 Web Worker 接入 React 管理界面。

## 开发命令

```powershell
npm run typecheck
npm test
npm run simulate:korean-catch-up
npm run simulate:taiwan-route
npm run calibrate -- outputs/calibration-errors.csv
npm run audit -- outputs/final-audit.json
npm run build
```

模拟逻辑位于 `src/simulation`，浏览器 Worker 位于 `src/worker`。所有数值参数集中放入 `src/data/config`，React 组件不得直接计算经济指标。

管理界面包含数据驱动的国策中心与外交事务模块。国策具有并行数量限制、互斥关系和渐进生效期；外交系统包含外交点数、双边关系、贸易协定、战略伙伴、制裁以及联合国、世界贸易组织等多边机制。外交关系会影响出口市场准入和外资信心，国防投入则通过安全指数与外交资源发挥作用。

国际经济模块逐月跟踪外汇储备、储备增减、年度侨汇流入、侨汇结汇贡献、进口覆盖月数、外债余额和偿债负担。设备投资中的进口部分必须由出口留汇、储备动用、外资、侨汇或生产性外债提供外汇；满足率不足时只约束进口资本品，不会误伤国内设备投资。外债按月计息并从储备还本付息，未付利息会资本化，负债率和偿债率分别按可比 GDP 与出口收入计算。生产性借款专款进入资本品用汇，不会同时虚增一般储备。侨汇也不会直接增加 GDP，而是按比例进入居民可支配收入、国民储蓄和侨资定向投资，再通过消费、资本形成及生产能力影响以后月份。

外债指标口径与风险阈值参考[国家外汇管理局外债数据说明](https://www.safe.gov.cn/safe/2026/0327/27301.html)。新中国初期外汇紧缺、建设用汇实行集中配置，改革开放后利用外资弥补资金、技术与外汇缺口的历史背景参考[国家外汇管理局外汇管理历史](https://www.safe.gov.cn/xiamen/2019/0930/1371.html)和[商务部利用外资回顾](https://chinawto.mofcom.gov.cn/article/ap/p/201912/20191202923754.shtml)。这些来源用于确定机制和数量级，历史锚点不会直接覆盖玩家路线的结果。

国策中心提供三类侨汇政策。“保护侨汇权益”提高正规渠道流入、家庭到账效率和结汇意愿；“侨资回乡创业”把更多侨汇转化为私人投资；“侨汇集中结汇”短期提高储备留存，但会压低流入意愿和家庭实际到账。保护权益与集中结汇互斥，政策均在过渡期内渐进生效。数量锚点参考[国家外汇管理局外汇储备数据](https://www.safe.gov.cn/safe/whcb/)和[世界银行 2024 年侨汇估算](https://blogs.worldbank.org/en/peoplemove/in-2024--remittance-flows-to-low--and-middle-income-countries-ar)，历史制度背景参考[1955 年保护侨汇政策](https://www.gqb.gov.cn/node2/node3/node5/node9/node102/userobject7ai1564.html)与[1982 年侨汇工作通知](https://policy.mofcom.gov.cn/claw/clawContent.shtml?id=36605)。

外交路线可在亲苏、平衡和亲西方之间选择。路线互斥，切换消耗外交点数并有 60 个月冷却期，阵营倾向约用 36 个月逐步到位；亲苏路线偏向对苏关系、科研和安全，亲西方路线偏向市场准入、外资和技术扩散，平衡路线维持多边回旋空间。所有收益与代价均通过关系、贸易、投资、科研和安全等中间变量传导。

联合国席位和世界贸易组织采用“历史进程 + 国际支持度”自动解锁，不是玩家选择的国策，也不提供手动申请按钮。联合国要求平均国际关系达到 8，且至少 8 个国家关系达到 20。多边贸易进程拆分为关贸总协定观察员、复关申请与 WTO 正式成员三个阶段：玩家可在改革、涉外法律、贸易协定和外交条件成熟后，分别从 1979 年、1982 年起主动争取前两个阶段；正式加入 WTO 不会早于该组织成立的 1995 年，并要求复关申请已推进至少 60 个月、平均关系达到 12、至少 10 个国家关系达到 25、开放度达到 35% 且已签署 3 项贸易协定。条件不足时，即使到达 1971 年或 2001 年史实日期也不会直接取得相应资格；条件在以后月份达成时才自动生效。史实参考节点为 1982 年取得关贸总协定观察员地位、1986 年提交复关申请和 2001 年加入 WTO，参见 [WTO 中国加入时间线](https://www.wto.org/french/thewto_f/acc_f/a1_chine_f.htm) 与 [WTO 中国加入历史说明](https://www.wto.org/english/news_e/pres01_e/pr243_e.htm)。提前达成时会同步记录为提前发生的历史事件，史实节点不再重复触发。

历史事件系统包含 35 个事件，其中 33 个按年月确定触发，联合国席位和加入世界贸易组织则只在资格条件达成后触发；事件覆盖没收官僚资本、清理在华外资企业、朝鲜战争、公私合营、工业化与经济调整、改革开放、关贸总协定观察员与复关申请、人口政策、公共卫生和国际经贸。React 游戏会在固定日期事件月份暂停，要求玩家从三个具有不同持续期、收益和代价的方案中决策；“外资清理”“朝鲜战争”“全行业公私合营”等关键事件具有专属路线。无界面批量模拟默认遵循历史路径，不会被交互阻塞。玩家选择和自动取得的国际资格都会写入存档，并在“历史事件”时间线中长期保留。

历史参考路线同时维护游戏内不变价产出、当年价人民币人均 GDP、现价美元人均 GDP 和国际可比 GDP 四种口径。GDP 总量排名使用 30 个主要经济体的轻量世界模型；全球人均 GDP 排名则使用完整参评经济体的公开锚点，并根据玩家路线相对史实收入的偏离连续移动。1978 年史实路线参考[世界银行现价美元序列](https://data.worldbank.org/indicator/NY.GDP.PCAP.CD?locations=CN)与[香港教育局经济教育材料](https://www.edb.gov.hk/attachment/en/curriculum-development/kla/pshe/references-and-resources/ces/support_materials_S3/M3.2%20%28Part1%29%20Economic%20performance%20of%20our%20country_e_2023%20Dec_clean.pdf)，校准为约 384 元、158.0 美元，GDP 总量第 10 名，全球人均 GDP 第 134/146 名；国际比较折算只影响统计、影响力和排名，不会直接增加产出。

部分人为政策事件允许玩家选择“阻止发生”。大跃进、人民公社化和文化大革命可以被否决，时间线会记录为“已避免”且不施加原事件的负面修正；保留下来的农业激励、有效资本形成、正常统计、教育科研、企业管理和制度秩序会在各自过渡期内逐月传导，并沉淀为资本、人才、技术、制度和全要素生产率存量。修正到期只会停止新增结构收益，不会把已经形成的生产率倒扣，因此后续改革和投资会在更高基数上继续复利。这些前置决策还会通过事件因果链降低三年经济困难的粮食、死亡率、工业和持续期冲击。史实选择始终使用现实校准路线，1978、1990、2000 年仍约为 158.0、321.0、976.3 美元；在相同年度预算和国策下，同时避免大跃进、公社化和文革的路线由模型计算为约 354.1、654.1、1659.6 美元，而不是修改史实锚点或直接给 GDP 加成。1978 年单独避免大跃进与公社化约为 256.5 美元，单独避免文革约为 219.8 美元。无界面史实路线仍按历史方案触发完整影响。

文化大革命的经济冲击改为分阶段传导。宏观形状参考[世界银行中国实际 GDP 增速序列](https://data.worldbank.org/indicator/NY.GDP.MKTP.KD.ZG?locations=CN)，史实路线模拟得到 1967、1968、1969、1970、1976 年同比约 -6.0%、-4.1%、14.7%、19.9%、-1.0%，分别对应公开序列约 -5.8%、-4.1%、16.9%、19.3%、-1.6%。长期损失参考蔡昉、都阳关于潜在受教育年限减少约 14.3% 及人力资本损失的[研究摘要](https://ccj.pku.edu.cn/article/info?id=301469698)、澳大利亚国立大学关于城市学校长期停课和大学招生中断的[研究论文](https://openresearch-repository.anu.edu.au/items/16cf1606-4a4c-4c6f-a62e-359c5b1e73a2)，以及 NBER 关于受冲击教育世代后来企业研发与专利表现的[研究](https://www.nber.org/papers/w27107)。模型据此分别作用于产业产出、能源、投资效率、教育效率、人力资本形成、科研、企业投资和制度秩序，并设置 1967—1968、恢复期及 1976 年的延迟阶段；所有变化都通过月度库存与流量积累，不直接给 GDP 赋值。

科技系统采用 12 个数据驱动节点组成的科技树，覆盖农业机械化、基础机床、电气化、化工材料、精密制造、电子工程、自动化、半导体、数字网络、先进能源和人工智能。科研预算、科研人才、大学覆盖、制度与产业需求共同产生月度科研产出；每个节点还要求前置科技、最低教育指数和最低科技能力。产业科技分为 0—5 层，科技指数高但产业节点或教育吸收能力不足时，“产业升级”国策的生产率、出口学习、投资效率和出口竞争力收益会按准备度折减，财政与能源代价则不会消失；出口模型使用有效产业科技而不是只看抽象科技指数。玩家可在科技页面更换当前研究目标，无界面模拟则确定性选择当前可研究节点。机制参考[世界银行企业技术采用研究](https://www.worldbank.org/en/topic/competitiveness/publication/technology-adoption-by-firms-in-developing-countries)、[国家统计局科技与教育指标说明](https://www.stats.gov.cn/english/PI/CurrentSurveysIndicators/200205/t20020517_27242.html)以及[NBER 关于文革教育中断与长期创新损失的研究](https://www.nber.org/papers/w27107)。文革史实路线除教育效率和科研产出下降外，还把科技树研究推进降至正常路径的 55%；保护教育科研机构的反事实路线则保持人才与节点积累连续。

国策中心新增“发展型金融、职业技术教育、出口工业区、产业升级”，可与扩大开放等国策组成韩国式出口工业化路线。模型参考[世界银行韩国现价美元人均 GDP 序列](https://data.worldbank.org/indicator/NY.GDP.PCAP.CD?locations=KR)以及[韩国国家统计机构的长期结构变化资料](https://sri.kostat.go.kr/boardDownload.es?bid=11772&list_no=347950&seq=1)，但不逐年强制拟合：顺差只有政策留存部分进入下月资本形成，出口学习必须同时具备真实出口、制造业基础、人力资本和对应科技节点，职业教育存在培养滞后，投资扩张还会增加消费、财政、能源和外需风险。种子 1949 的无界面预设在 1960、1970、1980、1990、2000 年分别约为 102.6、411.1、1357.9、3313.9、10999.5 美元；韩国参考值为 158.8、281.8、1745.6、6812.9、12710.3 美元。2000 年追赶路线达到韩国参考值的约 87%，处于同一收入数量级且没有直接改写 GDP。

国策中心提供韩国、台湾、香港、新加坡、美国和日本六组经济发展蓝图。韩国蓝图复用已经校准的发展型金融、职业技能和出口工业化机制；其余五组共新增十项模块化国策，分别侧重中小企业与电子产业、自由港与金融物流、招商制造与住房技能、研究型大学与风险资本、产业金融与质量制造。蓝图只是五项国策的快捷推荐组合，不形成路线锁定；采用后仍可逐项调整或跨蓝图混搭。每项政策都包含财政、能源、外需、金融、消费或分配方面的代价，详细资料和传导依据见[多元经济发展路线扩展设计](./发展路线扩展设计.md)。种子 1949 的六条无界面预设在 2000 年分别达到约 10999.5、4237.9、2884.5、5389.8、2708.7、2404.5 美元，并呈现不同的产业结构、开放度、教育积累、科技节点和财政风险，而不是按参考经济体 GDP 直接拟合。

1950 年朝鲜战争事件允许玩家选择反对战争并通过外交斡旋阻止冲突，或限制军事介入并推动停战。史实参战路线持续 37 个月，逐月计算额外死亡风险、国防财政支出、军工动员、民用投资与服务业挤出、贸易封锁、科研刺激，以及对美国、苏联和韩国关系目标的变化。苏联军事装备贷款作为限定军事用途的外债累计约 8.02 亿美元，不进入一般外储或生产性设备融资，战争期间按 1% 利率计息并在宽限期后优先偿还，1964 年按史实清偿；有限介入路线约形成 2.4 亿美元军事外债。数量级参考[中国社会科学院关于苏联对华贷款的研究](https://euroasia.cssn.cn/xsyj/xsyj_elswj/200912/t20091218_1784437.shtml)与[商务部利用外资史料](https://chinawto.mofcom.gov.cn/article/ap/p/201912/20191202923754.shtml)。阻止战争会记录为“已避免”，不产生这笔军事外债，并在五年内把原本被战争挤占的财政能力、投资效率、基础设施投入和资本品外汇用于民用积累；同时提高对韩国、美国及其他西方国家的关系目标，但承担对苏关系中期降温的外交代价。所有差异均经外汇、资本、财政和外交中间变量传导，不直接给 GDP 加固定值。

1964 年三线建设事件提供“遵循史实全面建设”“集中建设交通节点与核心基地”“不启动全面三线建设”三条路线。史实路线按 1964—1980 年设置为 192 个月，全面传导国防安全、政府资本形成效率、内陆基础设施、能源、科研、人口迁移、财政支出、民间投资、三次产业和制度效率；集中路线以较少财政挤出换取较低战略覆盖，取消路线改善民用配置效率但削弱国防纵深和内陆长期积累。历史量级采用约 2052.68 亿元总投入、1964—1975 年占全国基本建设投资 43.5%、1100 多个大中型项目及约 400 万迁移人口等资料；经济系数按历史策略中已经存在的工业和基建预算计算边际影响，避免重复计入投资规模。资料参见[西宁党建网三线建设史料](https://www.xndjw.gov.cn/website/contents/2919/99986.html)、[全国哲学社会科学工作办公室研究综述](https://www.nopss.gov.cn/n/2013/0424/c355627-21260121.html)以及同行评审论文[《Industrialization from scratch》](https://www.sciencedirect.com/science/article/abs/pii/S0304387821000754)。

三年经济困难提供专属救灾决策。玩家可以接受苏联的运输与医疗协作、加拿大和澳大利亚的粮食支持，以及美国参与的国际人道渠道援助，以协调与分配成本换取更高粮食供给、更低死亡率和更小的工农业收缩；接受援助会在 24 个月内逐步改善与这些援助来源国的双边关系，而不会给无关国家统一增加关系。玩家也可以选择依靠国内紧急赈济与政策纠偏，承担更高财政成本逐步恢复。援助效果通过粮食供给、死亡率、产业产出、财政支出、双边关系目标和外交声誉等中间变量传导，不直接修改人口或 GDP。

改革开放启动、中外合资经营企业法、设立经济特区、取得关贸总协定观察员地位和启动复关申请属于五项一次性“历史转折国策”。改革开放、合资法与经济特区从 1949 年起就在国策中心开放，不再受史实年份限制；改革开放按 1949 年初始制度、稳定和外交状态即可立即发动，合资法只要求改革开放已经启动，经济特区再要求改革开放和合资法均已启动，三项均不额外设置等待月数，因此玩家可在 1949 年同月依次完成。提前建设经济特区需要外交点数，并在 36 个月调整期内承担口岸、交通、监管建设支出和部分国内民间投资挤出；外资、出口和服务业收益仍由原事件修正逐月传导。五项国策具有递进前置关系，并检查制度效率、社会稳定、开放度、外交声誉、总体国际关系、贸易协定和外交点数。观察员地位不会直接授予 WTO 成员资格；复关申请需在观察员进程实施满 12 个月后发动；正式入世已从国策列表移除，改由国际组织系统在 1995 年以后检查复关谈判持续期及全部外交、开放条件并自动生效。国策中心会逐项显示当前缺失条件；提前实施只移动相应政策影响期，不会在史实年份重复结算。

## 无界面批量模拟

```powershell
# 策略 种子 次数 开始年份 结束年份 格式 输出文件
npm run simulate -- historical 1949 5 1949 2026 json outputs/baseline.json
```

策略可选：`historical`、`industrial`、`livelihood`、`education_technology`、`korean_catch_up`、`taiwan_sme_export`、`hong_kong_free_port`、`singapore_fdi_city`、`us_innovation_market`、`japan_quality_industry`、`debt`、`none`。格式可选 `json` 或 `csv`；省略输出文件时只在终端显示汇总。

模拟使用彼此独立、可序列化的人口/世界随机流与事件随机流。相同存档、策略和种子会得到相同年度序列；状态相关随机事件统一通过 Modifier 系统生效并记录到年度报告。

最终验收结果见[最终审计报告](./最终审计报告.md)。
