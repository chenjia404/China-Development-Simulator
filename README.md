# 中国国家发展模拟器

一款从 1949 年开始、以月为最小推进单位的国家经营模拟游戏。项目优先建设完全独立于界面的确定性模拟核心，再通过 Web Worker 接入 React 管理界面。

## 开发命令

```powershell
npm run typecheck
npm test
npm run calibrate -- outputs/calibration-errors.csv
npm run audit -- outputs/final-audit.json
npm run build
```

模拟逻辑位于 `src/simulation`，浏览器 Worker 位于 `src/worker`。所有数值参数集中放入 `src/data/config`，React 组件不得直接计算经济指标。

管理界面包含数据驱动的国策中心与外交事务模块。国策具有并行数量限制、互斥关系和渐进生效期；外交系统包含外交点数、双边关系、贸易协定、战略伙伴、制裁以及联合国、世界贸易组织等多边机制。外交关系会影响出口市场准入和外资信心，国防投入则通过安全指数与外交资源发挥作用。

外交路线可在亲苏、平衡和亲西方之间选择。路线互斥，切换消耗外交点数并有 60 个月冷却期，阵营倾向约用 36 个月逐步到位；亲苏路线偏向对苏关系、科研和安全，亲西方路线偏向市场准入、外资和技术扩散，平衡路线维持多边回旋空间。所有收益与代价均通过关系、贸易、投资、科研和安全等中间变量传导。

联合国席位和世界贸易组织采用“国际支持度”解锁。联合国要求平均国际关系达到 8，且至少 8 个国家关系达到 20；世界贸易组织从 1995 年起可申请，要求平均关系达到 12、至少 10 个国家关系达到 25、开放度达到 35% 并已签署 3 项贸易协定。玩家在史实日期前达标并加入时，会同步记录为提前发生的历史事件，史实节点不再重复触发。

历史事件系统包含 32 个按年月确定触发的事件，覆盖没收官僚资本、清理在华外资企业、公私合营、工业化与经济调整、改革开放、人口政策、公共卫生和国际经贸。React 游戏会在事件月份暂停，要求玩家从三个具有不同持续期、收益和代价的方案中决策；“外资清理”“全行业公私合营”等关键事件具有专属路线。无界面批量模拟默认遵循历史路径，不会被交互阻塞。玩家选择会写入存档，并在“历史事件”时间线中长期保留。

历史参考路线同时维护游戏内不变价产出、当年价人均 GDP 和国际可比 GDP 三种口径。1978、1990、2000 年的人均 GDP 与世界 GDP 位次使用国家统计局历史数据校准；国际比较折算只影响统计、影响力和排名，不会直接增加产出。

部分人为政策事件允许玩家选择“阻止发生”。大跃进和人民公社化可以被否决，时间线会记录为“已避免”且不施加原事件修正；这些前置决策还会通过事件因果链降低三年经济困难的粮食、死亡率、工业和持续期冲击。无界面史实路线仍按历史方案触发完整影响。

改革开放启动、中外合资经营企业法和加入世界贸易组织属于一次性“历史转折国策”，可在史实日期前主动实施。三项国策具有递进前置关系，并检查制度效率、社会稳定、开放度、外交声誉、总体国际关系和外交点数；合资法律框架需在改革开放运行满 12 个月后建立，提前入世则要求改革运行满 60 个月、合资法律运行满 36 个月及至少两项贸易协定，并会登记正式成员资格。国策中心会逐项显示当前缺失条件；提前实施只移动政策影响期，不会在史实年份重复结算。

## 无界面批量模拟

```powershell
# 策略 种子 次数 开始年份 结束年份 格式 输出文件
npm run simulate -- historical 1949 5 1949 2026 json outputs/baseline.json
```

策略可选：`historical`、`industrial`、`livelihood`、`education_technology`、`debt`、`none`。格式可选 `json` 或 `csv`；省略输出文件时只在终端显示汇总。

模拟使用彼此独立、可序列化的人口/世界随机流与事件随机流。相同存档、策略和种子会得到相同年度序列；状态相关随机事件统一通过 Modifier 系统生效并记录到年度报告。

最终验收结果见[最终审计报告](./最终审计报告.md)。
