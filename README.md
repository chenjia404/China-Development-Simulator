# 中国国家发展模拟器

一款从 1949 年开始、以月为最小推进单位的国家经营模拟游戏。项目优先建设完全独立于界面的确定性模拟核心，再通过 Web Worker 接入 React 管理界面。无界面核心已包含国民经济账户、人口家庭、企业所有制、中央地方财政，以及货币银行与国际收支账户。

维护或扩展项目前，请先阅读 [程序维护与扩展指南](./程序维护与扩展指南.md)。该文档包含模块边界、状态迁移、月度管线、国策与事件扩展、科技工业联动、测试校准以及 AI 代理执行清单。

## 开发命令

```powershell
npm run typecheck
npm test
npm run simulate:korean-catch-up
npm run simulate:taiwan-route
npm run data:audit
npm run calibrate -- outputs/calibration-errors.csv
npm run audit -- outputs/final-audit.json
npm run build
```

`historical-data-registry.json` 统一登记历史校准序列的发布者、来源地址、统计口径、单位、价格基准和分时期可信度。`npm run data:audit` 会在不访问网络的情况下检查来源引用、指标唯一性、年份覆盖和校准分组；人工复核日期保存在注册表元数据中。校准报告把 1949、1957、1978、2000、2020 年作为拟合组，把 1965、1990、2010 年作为留出验证组，2026 年单列为基于最近完整年度数据的预测基准，避免用拟合点通过率代替模型外验证。

模拟逻辑位于 `src/simulation`，浏览器 Worker 位于 `src/worker`。所有数值参数集中放入 `src/data/config`，React 组件不得直接计算经济指标。

经济产出同时受到供给能力和需求实现的约束。居民消费、投资、政府公共服务支出和出口构成总需求，上一月已经实现的内外需求会渐进影响下一月各产业产能利用率，再进入产业增加值和 GDP；出口不会直接重复计入 GDP。出口能力由科技树节点、教育吸收能力、十一类工业结构、基础设施、开放度、双边关系、贸易协定、制裁和外交路线共同决定。社会保障支出通过转移收入和降低居民预防性储蓄提高消费倾向与内需，同时承担财政支出、储蓄下降和潜在通胀代价，不作为无成本的 GDP 加成。

国民经济账户把农业、十一类工业、市场服务和公共服务归并为 14 类产品，逐月编制供给使用表。每类产品记录国内总产出、进口、出口、中间需求、居民消费、资本形成、政府消费和存货变化；供给与使用逐项守恒。生产法 GDP 由增加值汇总，收入法拆分劳动报酬、固定资本消耗、生产税净额和营业盈余，支出法拆分最终消费、资本形成、政府消费和净出口，三种口径经过显式统计调和后必须一致。中间品短缺不会同月反复计算，而是形成投入可得率，在达到严重短缺门槛后约束下一月生产。配置参考国家统计局历年投入产出表并集中保存在 `input-output.json`。

部门市场动态在同一套 14 类产品上维护相对价格、实际库存和目标库存，并汇总 CPI、PPI、GDP 平减指数、名义与实际工资指数、劳动收入份额和产出缺口。库存变化是年度化流量，进入库存存量前只累计十二分之一；短缺通过相对价格和投入可得率传导，实物商品库存超过目标较大幅度后才滞后抑制生产，服务业不会被错误当作可储存商品。参数集中在 `market-dynamics.json`，史实路线仍通过全部校准锚点。

详细人口账户把总人口展开为 18 个五岁年龄组并分别记录男女数量，每月结算出生、按年龄风险分配死亡和队列晋级，再与历史校准使用的 0—14、15—64、65 岁以上三段人口显式调和。家庭账户记录家庭户数、户均规模和少儿/老年抚养比；迁移账户从城乡人口变化中剔除自然增长，记录农村转城市、反向迁移与累计流量。旧存档会按当时三段人口确定性重建，不改变既有总人口路线。

企业部门账户把企业经济划分为国有、集体、民营、外商投资和混合所有制五类，逐月分配现有企业增加值、就业、投资、出口和营业盈余，并记录企业数量、工资、生产率与融资可得性。所有制份额由民营经营空间、企业家能力、技术商业化、开放度、外资和制度效率渐进变化；账户只分配宏观总量，不直接创造 GDP。公私合营、清理外资、恢复民营经济和对外开放因此会留下可追踪的企业结构变化，后续财政和银行模块可直接读取同一账户。

分级财政账户将现有合并财政拆为中央和地方收入、支出、余额、债务及中央对地方转移支付，并以 1994 年分税制为渐进结构节点。养老、医疗、失业、最低生活保障、家庭与儿童五项社会保障分别记录缴费、待遇、覆盖人数和人均待遇，结余进入社会保障储备。转移支付和社保缴费均是合并财政内部拆分，不会重复增加财政收入或支出。

管理界面包含数据驱动的国策中心与外交事务模块。国策具有并行数量限制、互斥关系和渐进生效期；外交系统包含外交点数、双边关系、贸易协定、战略伙伴、制裁、阵营取向、外交学说以及联合国、世界贸易组织等多边机制。外交关系会影响出口市场准入和外资信心，国防投入则通过安全指数与外交资源发挥作用。

国际经济模块逐月跟踪外汇储备、储备增减、年度侨汇流入、侨汇结汇贡献、进口覆盖月数、外债余额和偿债负担。设备投资中的进口部分必须由出口留汇、储备动用、外资、侨汇或生产性外债提供外汇；满足率不足时只约束进口资本品，不会误伤国内设备投资。外债按月计息并从储备还本付息，未付利息会资本化，负债率和偿债率分别按可比 GDP 与出口收入计算。生产性借款专款进入资本品用汇，不会同时虚增一般储备。侨汇也不会直接增加 GDP，而是按比例进入居民可支配收入、国民储蓄和侨资定向投资，再通过消费、资本形成及生产能力影响以后月份。

外债指标口径与风险阈值参考[国家外汇管理局外债数据说明](https://www.safe.gov.cn/safe/2026/0327/27301.html)。新中国初期外汇紧缺、建设用汇实行集中配置，改革开放后利用外资弥补资金、技术与外汇缺口的历史背景参考[国家外汇管理局外汇管理历史](https://www.safe.gov.cn/xiamen/2019/0930/1371.html)和[商务部利用外资回顾](https://chinawto.mofcom.gov.cn/article/ap/p/201912/20191202923754.shtml)。这些来源用于确定机制和数量级，历史锚点不会直接覆盖玩家路线的结果。

国策中心提供三类侨汇政策。“保护侨汇权益”提高正规渠道流入、家庭到账效率和结汇意愿；“侨资回乡创业”把更多侨汇转化为私人投资；“侨汇集中结汇”短期提高储备留存，但会压低流入意愿和家庭实际到账。保护权益与集中结汇互斥，政策均在过渡期内渐进生效。数量锚点参考[国家外汇管理局外汇储备数据](https://www.safe.gov.cn/safe/whcb/)和[世界银行 2024 年侨汇估算](https://blogs.worldbank.org/en/peoplemove/in-2024--remittance-flows-to-low--and-middle-income-countries-ar)，历史制度背景参考[1955 年保护侨汇政策](https://www.gqb.gov.cn/node2/node3/node5/node9/node102/userobject7ai1564.html)与[1982 年侨汇工作通知](https://policy.mofcom.gov.cn/claw/clawContent.shtml?id=36605)。

外交分为两个可以自由组合的决策层。阵营取向可在亲苏、平衡和亲西方之间选择；外交学说则提供维持现状、革命国际主义、放弃对外革命与和平共处、不结盟与战略自主、经贸外交优先、多边制度主义、区域睦邻合作七条路线。两层各自切换、各自消耗外交点数并有 60 个月冷却期，效果约用 36 个月逐步到位。例如和平共处会改善美国、日本、韩国等非苏系国家关系，但降低苏联、朝鲜、越南等苏系国家关系；经贸外交提高市场、外资和技术扩散，同时付出安全与外交资源代价。所有效果均通过双边关系、贸易、投资、科研、安全和国际声誉等中间变量传导，不直接修改 GDP 或贸易额。学说设计参考中国提出的[和平共处五项原则](https://www.mfa.gov.cn/ziliao_674904/1179_674909/202406/t20240628_11444300.shtml)、印度外交政策中的[不结盟与战略自主](https://www.mea.gov.in/indian-foreign-policy.htm)、日本外务省的[经济外交框架](https://www.mofa.go.jp/policy/economy/index.html)、联合国的[多边体系说明](https://www.un.org/en/global-issues/multilateral-system)以及东盟《[东南亚友好合作条约](https://agreement.asean.org/media/download/20131230235433.pdf)》。这些资料用于提炼取舍机制，不代表对现实国家政策作价值判断。

外交页面另提供暂停援助、有限人道援助、社会主义伙伴重点援助、南南发展合作、史实综合援外、经贸技术合作和扩大国际主义援助七种对外援助方案。1950—1980 年史实方案按当年价累计 365 亿元人民币，依据年度官方汇率折算约 170.4 亿美元；1950 年以前不结算援助。史实综合援外是现有历史校准的中性基线，避免重复扣除已经隐含在基准参数中的历史成本。停止援助会释放国内投资、科研人员和援外用汇，但降低朝鲜、越南等历史伙伴的关系目标、国际声誉与出口合作网络；成套项目或经贸技术合作可形成工业工程经验和海外市场网络，同时占用财政、设备和人才。方案用 12 个月渐进到位、24 个月冷却，援外支出作为财政总支出组成项而非额外重复相加。历史阶段划分、66 个受援国和 880 个成套项目参考[国家统计局回顾](https://www.stats.gov.cn/zt_18555/ztfx/xzg50nxlfxbg/202303/t20230301_1920452.html)，援助方式与改革阶段参考[国务院新闻办公室《中国的对外援助》白皮书](https://www.cidca.gov.cn/2018-08/06/c_129925064_2.htm)，累计金额量级参考[中国社会科学院研究](https://niis.cssn.cn/webpic/web/niis/upload/2012/12/d20121209111156431.pdf)，美元折算采用世界银行[官方汇率口径](https://data.worldbank.org/indicator/PA.NUS.FCRF?locations=CN&type=points)。

中美建交是外交页面中的一次性外交国策。史实路线于 1979 年 1 月建交；交互路线可在对美关系、声誉、稳定、制度效率和外交点达标后提前发动，也可延迟。关系越好，谈判时间越短；建交后科技、教育、贸易、外资和外交合作约用五年成熟，并在约一年后形成对美贸易协定渠道。史实时间是经济倍率的中性校准基线，提前路线更早积累留学生与科研人才、技术扩散、出口客户和资本，延迟路线则错失对应月度流量；后续建交不会直接补回已经损失的资本、人才和技术存量。关系正常化会提高美国、日本和韩国的关系目标，并使苏联、朝鲜的关系目标承受有限调整。中美于 1979 年 1 月正式建交及同期科技、文化、教育、商业和空间合作安排参考[外交部历史回顾](https://www.mfa.gov.cn/ziliao_674904/wjs_674919/2159_674923/200011/t20001107_10251069.shtml)与[外交部条约数据库](https://treaty.mfa.gov.cn/web/detail1.jsp?objid=1531876547249)；首批 52 名访问学者和计划接收 500—700 名留学生、研究生及访问学者参考[教育部留学史料](https://www.moe.gov.cn/jyb_xwfb/xw_zt/moe_357/s3580/moe_2448/moe_2470/tnull_41369.html)；双边贸易由 1978 年 11 亿美元增至 1979 年 23 亿美元、1980 年预计约 40 亿美元，以及 13 项科技工作协议参考[美国国务院历史文献](https://history.state.gov/historicaldocuments/frus1977-80v13/d322)；1979 年贸易协定及 1980 年非歧视待遇生效参考[美国国家档案馆](https://www.archives.gov/federal-register/codification/proclamations/04697.html)。这些资料用于确定传导方向和成熟期，不把同期全部增长归因于建交。

联合国席位和世界贸易组织采用“历史进程 + 国际支持度”自动解锁，不是玩家选择的国策，也不提供手动申请按钮。联合国要求平均国际关系达到 8，且至少 8 个国家关系达到 20。多边贸易进程拆分为关贸总协定观察员、复关申请与 WTO 正式成员三个阶段：玩家可在改革、涉外法律、贸易协定和外交条件成熟后，分别从 1979 年、1982 年起主动争取前两个阶段；正式加入 WTO 不会早于该组织成立的 1995 年，并要求复关申请已推进至少 60 个月、平均关系达到 12、至少 10 个国家关系达到 25、开放度达到 35% 且已签署 3 项贸易协定。条件不足时，即使到达 1971 年或 2001 年史实日期也不会直接取得相应资格；条件在以后月份达成时才自动生效。史实参考节点为 1982 年取得关贸总协定观察员地位、1986 年提交复关申请和 2001 年加入 WTO，参见 [WTO 中国加入时间线](https://www.wto.org/french/thewto_f/acc_f/a1_chine_f.htm) 与 [WTO 中国加入历史说明](https://www.wto.org/english/news_e/pres01_e/pr243_e.htm)。提前达成时会同步记录为提前发生的历史事件，史实节点不再重复触发。

历史事件系统包含 37 个事件，其中 34 个按年月确定触发，联合国席位、加入世界贸易组织和中美建交则分别由资格条件或外交进程触发；事件覆盖没收官僚资本、清理在华外资企业、朝鲜战争、公私合营、民营经济法律承认、工业化与经济调整、改革开放、关贸总协定观察员与复关申请、人口政策、公共卫生和国际经贸。React 游戏会在固定日期事件月份暂停，要求玩家从三个具有不同持续期、收益和代价的方案中决策；“取消经济特权与清理在华外资企业”的史实方案会在 60 个月清理期内把新增外资流入降低 100%，有偿渐进清理和保留受监管外资则分别保留 65% 和 90% 的流入渠道。“朝鲜战争”“全行业公私合营”等关键事件同样具有专属路线。无界面批量模拟默认遵循历史路径，不会被交互阻塞。玩家选择、建交结果和自动取得的国际资格都会写入存档，并在“历史事件”时间线中长期保留。

历史参考路线同时维护游戏内不变价产出、当年价人民币人均 GDP、现价美元人均 GDP 和国际可比 GDP 四种口径。GDP 总量排名使用 31 个主要经济体的轻量世界模型；全球人均 GDP 排名则使用完整参评经济体的公开锚点，并根据玩家路线相对史实收入的偏离连续移动。1978 年史实路线参考[世界银行现价美元序列](https://data.worldbank.org/indicator/NY.GDP.PCAP.CD?locations=CN)与[香港教育局经济教育材料](https://www.edb.gov.hk/attachment/en/curriculum-development/kla/pshe/references-and-resources/ces/support_materials_S3/M3.2%20%28Part1%29%20Economic%20performance%20of%20our%20country_e_2023%20Dec_clean.pdf)，校准为约 384 元、158.0 美元，GDP 总量第 10 名，全球人均 GDP 第 134/146 名；国际比较折算只影响统计、影响力和排名，不会直接增加产出。

“国家总览”首页直接提供最新可比年份摘要，可在历史、韩国、日本和台湾之间切换，并同时看到 GDP、人均 GDP、总人口和世界经济排名差距；点击“查看完整年度对比”可进入“统计”页面查看完整时间序列。选择“历史”时，按 1949、1957、1965、1978、1990、2000、2010 和 2020 年八个史实锚点展示本局与中国真实历史的实际 GDP、同口径人均 GDP、总人口和世界经济排名，数据直接复用 `calibration-targets.json`；选择韩国、日本或台湾时，则按 1960—2020 年九个锚点使用同期现价美元 GDP、现价美元人均 GDP、人口和名义 GDP 世界排名进行横向比较。日韩数据来自世界银行，台湾数据来自官方国民账户，集中存放在 `comparison-economy-targets.json`。所有对比只用于展示，不会写回玩家状态或强制回拉反事实路线；2026 年预测校准目标也不会混入真实历史表。

部分人为政策事件允许玩家选择“阻止发生”。大跃进、人民公社化和文化大革命可以被否决，时间线会记录为“已避免”且不施加原事件的负面修正；保留下来的农业激励、有效资本形成、正常统计、教育科研、企业管理和制度秩序会在各自过渡期内逐月传导，并沉淀为资本、人才、技术、制度和全要素生产率存量。避免事件不再通过长期的三次产业产出倍率制造临时高基数，因而倍率到期时也不会出现 GDP 断崖；修正到期只会停止新增投资、教育或结构生产率流量，不会把已经形成的存量倒扣，后续改革和投资继续在玩家自己的基数上复利。这些前置决策还会通过事件因果链降低三年经济困难的粮食、死亡率、工业和持续期冲击。史实选择始终使用现实校准路线，1978、1990、2000 年仍约为 158.0、321.1、976.4 美元；反事实路线完全由自身状态演化，不使用后续史实 GDP 锚点覆盖结果。无界面史实路线仍按历史方案触发完整影响。

文化大革命的经济冲击改为分阶段传导。宏观形状参考[世界银行中国实际 GDP 增速序列](https://data.worldbank.org/indicator/NY.GDP.MKTP.KD.ZG?locations=CN)，史实路线模拟得到 1967、1968、1969、1970、1976 年同比约 -6.0%、-4.1%、14.7%、19.9%、-1.0%，分别对应公开序列约 -5.8%、-4.1%、16.9%、19.3%、-1.6%。教育与科研不再只使用十年倍率，而是逐月维护高等教育招生能力、学术体系连续性、科研人才代际缺口、累计严重停招月数和科研人才永久损失；前54个月近乎停招、随后招生仍严重受限，1977年后恢复招生和科研组织，但代际缺口及创新生产率影响继续跨越十余年。中国科学院史料记载北京地区170名高级研究人员中131人被审查或打击、全院229名工作人员被迫害致死，机构和学部也经历停摆、撤并，参见[中国科学院自然科学史研究所史料](https://www.ihns.ac.cn/kxcb_/kxjd/202212/t20221206_6567194.html)与[中国科学院院史](https://kxcb.las.ac.cn/ysz_detail/62.html)；高考停招十年及人才断层参考[教育部资料](https://www.moe.gov.cn/jyb_xwfb/xw_zt/moe_357/s3580/moe_2448/moe_2470/tnull_41368.html)，长期创新损失参考[NBER研究](https://www.nber.org/papers/w27107)。模型据此分别作用于产业产出、能源、投资效率、教育培养流量、科研人才存量、科技树推进、企业投资和制度秩序；所有变化都通过月度库存与流量积累，不直接给 GDP 赋值。

科技系统采用 34 个数据驱动节点组成的七层科技树，分别沿农业、资源材料、机械交通、化工医药、电气能源、电子信息、精密制造、航空航天和智能制造分支推进。每个节点除前置科技、科研成本、最低教育指数和最低科技能力外，还明确指定受影响的工业类别及其生产率、出口倍率；冶金不会直接替电子工业升级，通信、半导体、工业机器人等专门技术会把能力逐级传导到对应工业。科研预算、科研人才、大学覆盖、制度与产业需求共同产生月度科研产出；当月科研产出超过基础组织门槛后，实验室和工程团队可以并行承担子课题，形成有上限的规模效应，避免高投入追赶路线被单一节点队列人为卡死。科技指数高但产业节点或教育吸收能力不足时，“产业升级”国策的生产率、出口学习、投资效率和出口竞争力收益会按准备度折减，财政与能源代价则不会消失。玩家可在科技页面更换当前研究目标，无界面模拟则确定性选择当前可研究节点。机制参考[世界银行企业技术采用研究](https://www.worldbank.org/en/topic/competitiveness/publication/technology-adoption-by-firms-in-developing-countries)、[国家统计局高技术产业统计分类](https://www.stats.gov.cn/zs/tjws/tjbz/202301/t20230101_1903766.html)以及[NBER 关于文革教育中断与长期创新损失的研究](https://www.nber.org/papers/w27107)。文革史实路线除教育效率和科研产出下降外，还会破坏人才与科技树节点的连续积累。

科技工业体系提供综合基础、轻工出口、重工装备、电子信息、医药化工、绿色电气和高端装备七条长期发展路线。路线不会直接授予科技或产出，而是改变自动研究优先级、专项与非专项研究效率、十一类工业的目标份额、生产率、出口竞争力及能源需求；所有效果用 48 个月渐进到位。玩家仍可手动选择路线外节点，但会按非专项效率推进，科技前置、教育和科技能力门槛也不会被绕过。切换路线会损失当前研究进度的 35%，并触发 36 个月冷却，避免无成本逐月追逐最优加成；旧存档确定性迁移为不带额外倍率的“综合基础体系”。

工业系统在第二产业总量之下进一步维护十一类结构：采矿能源、基础材料、消费品、建筑、通用机械、交通设备、化工医药、电气设备、电子通信、精密医疗仪器和航空航天高端装备。每类分别具有能源、技能、科技节点和出口倾向，产出份额按月缓慢调整；细分类别增加值之和始终等于第二产业，避免重复计算 GDP。工业复杂度影响第二产业生产能力，类别技术准备度和出口倾向共同决定工业品出口上限及出口构成，因此只有抽象科技指数而没有机床、材料、电子等产业节点时，无法直接形成高附加值制造与出口。分类参考[国家统计局高技术制造业口径](https://www.stats.gov.cn/zs/tjws/tjbz/202301/t20230101_1903766.html)及[第五次全国经济普查的新兴产业分类](https://www.stats.gov.cn/sj/zxfb/202412/t20241226_1957891.html)。

国策中心新增“发展型金融、职业技术教育、出口工业区、产业升级”，可与扩大开放等国策组成韩国式出口工业化路线。模型参考[世界银行韩国现价美元人均 GDP 序列](https://data.worldbank.org/indicator/NY.GDP.PCAP.CD?locations=KR)以及[韩国国家统计机构的长期结构变化资料](https://sri.kostat.go.kr/boardDownload.es?bid=11772&list_no=347950&seq=1)，但不逐年强制拟合：顺差只有政策留存部分进入下月资本形成，出口学习必须同时具备真实出口、制造业基础、人力资本和对应科技节点，职业教育存在培养滞后，投资扩张还会增加消费、财政、能源和外需风险。种子 1949 的无界面预设在 1960、1970、1980、1990、2000 年分别约为 79.8、289.3、1235.4、3231.1、11658.1 美元；韩国参考值为 158.8、281.8、1745.6、6812.9、12710.3 美元。2000 年追赶路线达到韩国参考值的约 92%，处于同一收入数量级且没有直接改写 GDP。

国策中心提供韩国、台湾、香港、新加坡、美国和日本六组经济发展蓝图。韩国蓝图复用已经校准的发展型金融、职业技能和出口工业化机制；其余五组共新增十项模块化国策，分别侧重中小企业与电子产业、自由港与金融物流、招商制造与住房技能、研究型大学与风险资本、产业金融与质量制造。蓝图只是五项国策的快捷推荐组合，不形成路线锁定；采用后仍可逐项调整或跨蓝图混搭。每项政策都包含财政、能源、外需、金融、消费或分配方面的代价，详细资料和传导依据见[多元经济发展路线扩展设计](./发展路线扩展设计.md)。种子 1949 的六条无界面预设在 2000 年分别达到约 11658.1、4370.0、3146.4、4594.4、2931.6、2545.0 美元，并呈现不同的产业结构、开放度、教育积累、科技节点和财政风险，而不是按参考经济体 GDP 直接拟合。

1950 年朝鲜战争事件允许玩家选择反对战争并通过外交斡旋阻止冲突，或限制军事介入并推动停战。史实参战路线持续 37 个月，逐月计算额外死亡风险、国防财政支出、军工动员、民用投资与服务业挤出、贸易封锁、科研刺激，以及对美国、苏联和韩国关系目标的变化。苏联军事装备贷款作为限定军事用途的外债累计约 8.02 亿美元，不进入一般外储或生产性设备融资，战争期间按 1% 利率计息并在宽限期后优先偿还，1964 年按史实清偿；有限介入路线约形成 2.4 亿美元军事外债。数量级参考[中国社会科学院关于苏联对华贷款的研究](https://euroasia.cssn.cn/xsyj/xsyj_elswj/200912/t20091218_1784437.shtml)与[商务部利用外资史料](https://chinawto.mofcom.gov.cn/article/ap/p/201912/20191202923754.shtml)。阻止战争会记录为“已避免”，不产生这笔军事外债，并在五年内把原本被战争挤占的财政能力、投资效率、基础设施投入和资本品外汇用于民用积累；同时提高对韩国、美国及其他西方国家的关系目标，但承担对苏关系中期降温的外交代价。所有差异均经外汇、资本、财政和外交中间变量传导，不直接给 GDP 加固定值。

1964 年三线建设事件提供“遵循史实全面建设”“集中建设交通节点与核心基地”“不启动全面三线建设”三条路线。史实路线按 1964—1980 年设置为 192 个月，全面传导国防安全、政府资本形成效率、内陆基础设施、能源、科研、人口迁移、财政支出、民间投资、三次产业和制度效率；集中路线以较少财政挤出换取较低战略覆盖，取消路线改善民用配置效率但削弱国防纵深和内陆长期积累。历史量级采用约 2052.68 亿元总投入、1964—1975 年占全国基本建设投资 43.5%、1100 多个大中型项目及约 400 万迁移人口等资料；经济系数按历史策略中已经存在的工业和基建预算计算边际影响，避免重复计入投资规模。资料参见[西宁党建网三线建设史料](https://www.xndjw.gov.cn/website/contents/2919/99986.html)、[全国哲学社会科学工作办公室研究综述](https://www.nopss.gov.cn/n/2013/0424/c355627-21260121.html)以及同行评审论文[《Industrialization from scratch》](https://www.sciencedirect.com/science/article/abs/pii/S0304387821000754)。

三年经济困难提供专属救灾决策。玩家可以接受苏联的运输与医疗协作、加拿大和澳大利亚的粮食支持，以及美国参与的国际人道渠道援助，以协调与分配成本换取更高粮食供给、更低死亡率和更小的工农业收缩；接受援助会在 24 个月内逐步改善与这些援助来源国的双边关系，而不会给无关国家统一增加关系。玩家也可以选择依靠国内紧急赈济与政策纠偏，承担更高财政成本逐步恢复。援助效果通过粮食供给、死亡率、产业产出、财政支出、双边关系目标和外交声誉等中间变量传导，不直接修改人口或 GDP。

国策中心现有十五项一次性“历史转折国策”：统一财政经济、土地改革、第一个五年计划、三线建设、改革开放、中外合资经营企业法、经济特区、私营经济法律承认、城市经济体制改革、社会主义市场经济目标、分税制、供给侧结构性改革、关贸总协定观察员地位、复关申请和跨境互联互通倡议。适合由政府主动推动的治理、建设、改革和国际合作事件，都可在史实日期前由玩家发动；战争、灾害、经济危机和政治运动仍由历史事件系统处理，不会变成无条件收益按钮。改革开放、合资法与经济特区仍可从 1949 年起依次启动，私营经济法律承认可在改革启动且民营经营空间与企业家能力达标后无外交点成本实施；财政统一和土地改革也可立即实施。五年计划、三线建设及后续改革则要求前置方案运行一定月数，并检查制度效率、稳定、教育、科技、城镇化和产业结构。国内改革不消耗外交点数，但建设与制度转轨会通过财政支出、民间投资或短期产出承担成本；多边贸易和跨境合作还要求国际关系、支持国家、贸易协定、声誉、影响力及外交点数。观察员地位不会直接授予 WTO 成员资格，正式入世仍由国际组织系统在 1995 年以后检查复关谈判持续期及全部条件后自动生效。国策中心逐项显示缺失条件；提前实施只移动原事件影响期，决策写入存档后不可撤销，也不会在史实年份重复结算。

## 无界面批量模拟

```powershell
# 策略 种子 次数 开始年份 结束年份 格式 输出文件
npm run simulate -- historical 1949 5 1949 2026 json outputs/baseline.json
```

策略可选：`historical`、`industrial`、`livelihood`、`education_technology`、`korean_catch_up`、`taiwan_sme_export`、`hong_kong_free_port`、`singapore_fdi_city`、`us_innovation_market`、`japan_quality_industry`、`debt`、`none`。格式可选 `json` 或 `csv`；省略输出文件时只在终端显示汇总。

模拟使用彼此独立、可序列化的人口/世界随机流与事件随机流。相同存档、策略和种子会得到相同年度序列；状态相关随机事件统一通过 Modifier 系统生效并记录到年度报告。

最终验收结果见[最终审计报告](./最终审计报告.md)。
