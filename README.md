# 中国国家发展模拟器

一款从 1949 年开始、以月为最小推进单位的国家经营模拟游戏。项目优先建设完全独立于界面的确定性模拟核心，再通过 Web Worker 接入 React 管理界面。

## 开发命令

```powershell
npm run typecheck
npm test
npm run calibrate -- outputs/calibration-errors.csv
npm run audit -- outputs/final-audit.json
npm run build
```

模拟逻辑位于 `src/simulation`，浏览器 Worker 位于 `src/worker`。所有数值参数集中放入 `src/data/config`，React 组件不得直接计算经济指标。

管理界面包含数据驱动的国策中心与外交事务模块。国策具有并行数量限制、互斥关系和渐进生效期；外交系统包含外交点数、双边关系、贸易协定、战略伙伴、制裁以及联合国、世界贸易组织等多边机制。外交关系会影响出口市场准入和外资信心，国防投入则通过安全指数与外交资源发挥作用。

国际经济模块逐月跟踪外汇储备、储备增减、年度侨汇流入、侨汇结汇贡献和进口覆盖月数。贸易顺差、外商直接投资、侨汇结汇、储备收益及进口支付共同决定储备变化；储备不足会约束进口能力。侨汇不会直接增加 GDP，而是按比例进入居民可支配收入、国民储蓄和侨资定向投资，再通过消费能力、资本形成及生产能力影响以后月份的经济发展。

国策中心提供三类侨汇政策。“保护侨汇权益”提高正规渠道流入、家庭到账效率和结汇意愿；“侨资回乡创业”把更多侨汇转化为私人投资；“侨汇集中结汇”短期提高储备留存，但会压低流入意愿和家庭实际到账。保护权益与集中结汇互斥，政策均在过渡期内渐进生效。数量锚点参考[国家外汇管理局外汇储备数据](https://www.safe.gov.cn/safe/whcb/)和[世界银行 2024 年侨汇估算](https://blogs.worldbank.org/en/peoplemove/in-2024--remittance-flows-to-low--and-middle-income-countries-ar)，历史制度背景参考[1955 年保护侨汇政策](https://www.gqb.gov.cn/node2/node3/node5/node9/node102/userobject7ai1564.html)与[1982 年侨汇工作通知](https://policy.mofcom.gov.cn/claw/clawContent.shtml?id=36605)。

外交路线可在亲苏、平衡和亲西方之间选择。路线互斥，切换消耗外交点数并有 60 个月冷却期，阵营倾向约用 36 个月逐步到位；亲苏路线偏向对苏关系、科研和安全，亲西方路线偏向市场准入、外资和技术扩散，平衡路线维持多边回旋空间。所有收益与代价均通过关系、贸易、投资、科研和安全等中间变量传导。

联合国席位和世界贸易组织采用“历史进程 + 国际支持度”自动解锁，不是玩家选择的国策，也不提供手动申请按钮。联合国要求平均国际关系达到 8，且至少 8 个国家关系达到 20。多边贸易进程拆分为关贸总协定观察员、复关申请与 WTO 正式成员三个阶段：玩家可在改革、涉外法律、贸易协定和外交条件成熟后，分别从 1979 年、1982 年起主动争取前两个阶段；正式加入 WTO 不会早于该组织成立的 1995 年，并要求复关申请已推进至少 60 个月、平均关系达到 12、至少 10 个国家关系达到 25、开放度达到 35% 且已签署 3 项贸易协定。条件不足时，即使到达 1971 年或 2001 年史实日期也不会直接取得相应资格；条件在以后月份达成时才自动生效。史实参考节点为 1982 年取得关贸总协定观察员地位、1986 年提交复关申请和 2001 年加入 WTO，参见 [WTO 中国加入时间线](https://www.wto.org/french/thewto_f/acc_f/a1_chine_f.htm) 与 [WTO 中国加入历史说明](https://www.wto.org/english/news_e/pres01_e/pr243_e.htm)。提前达成时会同步记录为提前发生的历史事件，史实节点不再重复触发。

历史事件系统包含 35 个事件，其中 33 个按年月确定触发，联合国席位和加入世界贸易组织则只在资格条件达成后触发；事件覆盖没收官僚资本、清理在华外资企业、朝鲜战争、公私合营、工业化与经济调整、改革开放、关贸总协定观察员与复关申请、人口政策、公共卫生和国际经贸。React 游戏会在固定日期事件月份暂停，要求玩家从三个具有不同持续期、收益和代价的方案中决策；“外资清理”“朝鲜战争”“全行业公私合营”等关键事件具有专属路线。无界面批量模拟默认遵循历史路径，不会被交互阻塞。玩家选择和自动取得的国际资格都会写入存档，并在“历史事件”时间线中长期保留。

历史参考路线同时维护游戏内不变价产出、当年价人民币人均 GDP、现价美元人均 GDP 和国际可比 GDP 四种口径。GDP 总量排名使用 30 个主要经济体的轻量世界模型；全球人均 GDP 排名则使用完整参评经济体的公开锚点，并根据玩家路线相对史实收入的偏离连续移动。1978 年史实路线参考[世界银行现价美元序列](https://data.worldbank.org/indicator/NY.GDP.PCAP.CD?locations=CN)与[香港教育局经济教育材料](https://www.edb.gov.hk/attachment/en/curriculum-development/kla/pshe/references-and-resources/ces/support_materials_S3/M3.2%20%28Part1%29%20Economic%20performance%20of%20our%20country_e_2023%20Dec_clean.pdf)，校准为约 381 元、156.7 美元，GDP 总量第 10 名，全球人均 GDP 第 134/146 名；国际比较折算只影响统计、影响力和排名，不会直接增加产出。

部分人为政策事件允许玩家选择“阻止发生”。大跃进和人民公社化可以被否决，时间线会记录为“已避免”且不施加原事件的负面修正；保留下来的农业激励、正常投资、教育科研和制度秩序会作为长期机会收益逐月传导。这些前置决策还会通过事件因果链降低三年经济困难的粮食、死亡率、工业和持续期冲击。审计中，史实/同时避免两项运动的 1978 年人均 GDP 分别为 155.8/175.1 美元，全球人均排名为第 134/132 名。无界面史实路线仍按历史方案触发完整影响。

1950 年朝鲜战争事件允许玩家选择反对战争并通过外交斡旋阻止冲突，或限制军事介入并推动停战。史实参战路线持续 37 个月，逐月计算额外死亡风险、国防财政支出、军工动员、民用投资与服务业挤出、贸易封锁、科研刺激，以及对美国、苏联和韩国关系目标的变化；阻止战争会记录为“已避免”并取消上述战争冲击，对韩关系会从当前水平逐月改善，但需要承担对苏关系降温的外交代价。

1964 年三线建设事件提供“遵循史实全面建设”“集中建设交通节点与核心基地”“不启动全面三线建设”三条路线。史实路线按 1964—1980 年设置为 192 个月，全面传导国防安全、政府资本形成效率、内陆基础设施、能源、科研、人口迁移、财政支出、民间投资、三次产业和制度效率；集中路线以较少财政挤出换取较低战略覆盖，取消路线改善民用配置效率但削弱国防纵深和内陆长期积累。历史量级采用约 2052.68 亿元总投入、1964—1975 年占全国基本建设投资 43.5%、1100 多个大中型项目及约 400 万迁移人口等资料；经济系数按历史策略中已经存在的工业和基建预算计算边际影响，避免重复计入投资规模。资料参见[西宁党建网三线建设史料](https://www.xndjw.gov.cn/website/contents/2919/99986.html)、[全国哲学社会科学工作办公室研究综述](https://www.nopss.gov.cn/n/2013/0424/c355627-21260121.html)以及同行评审论文[《Industrialization from scratch》](https://www.sciencedirect.com/science/article/abs/pii/S0304387821000754)。

三年经济困难提供专属救灾决策。玩家可以接受苏联的运输与医疗协作、加拿大和澳大利亚的粮食支持，以及美国参与的国际人道渠道援助，以协调与分配成本换取更高粮食供给、更低死亡率和更小的工农业收缩；接受援助会在 24 个月内逐步改善与这些援助来源国的双边关系，而不会给无关国家统一增加关系。玩家也可以选择依靠国内紧急赈济与政策纠偏，承担更高财政成本逐步恢复。援助效果通过粮食供给、死亡率、产业产出、财政支出、双边关系目标和外交声誉等中间变量传导，不直接修改人口或 GDP。

改革开放启动、中外合资经营企业法、取得关贸总协定观察员地位和启动复关申请属于四项一次性“历史转折国策”。改革开放与合资法从 1949 年起就在国策中心开放，不再受 1965/1966 年的硬编码限制；改革开放按 1949 年初始制度、稳定和外交状态即可立即发动，合资法只要求改革开放已经启动，不再额外等待 12 个月，因此玩家可在 1949 年同月依次完成两项国策。四项国策具有递进前置关系，并检查制度效率、社会稳定、开放度、外交声誉、总体国际关系、贸易协定和外交点数。观察员地位不会直接授予 WTO 成员资格；复关申请需在观察员进程实施满 12 个月后发动；正式入世已从国策列表移除，改由国际组织系统在 1995 年以后检查复关谈判持续期及全部外交、开放条件并自动生效。国策中心会逐项显示当前缺失条件；提前实施只移动相应政策影响期，不会在史实年份重复结算。

## 无界面批量模拟

```powershell
# 策略 种子 次数 开始年份 结束年份 格式 输出文件
npm run simulate -- historical 1949 5 1949 2026 json outputs/baseline.json
```

策略可选：`historical`、`industrial`、`livelihood`、`education_technology`、`debt`、`none`。格式可选 `json` 或 `csv`；省略输出文件时只在终端显示汇总。

模拟使用彼此独立、可序列化的人口/世界随机流与事件随机流。相同存档、策略和种子会得到相同年度序列；状态相关随机事件统一通过 Modifier 系统生效并记录到年度报告。

最终验收结果见[最终审计报告](./最终审计报告.md)。
